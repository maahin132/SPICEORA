# Contributing

## Development setup

Follow the local setup instructions in [README.md](README.md). Never commit `.env`, credentials, database dumps, virtual environments, `node_modules`, or generated build output.

## Before opening a pull request

- Run the relevant backend checks and tests from `backend/`.
- Run `npm run build` in `frontend/`.
- Update documentation when changing setup, API, security, or architecture behavior.
- Keep changes focused and explain user-visible behavior in the pull request.

Use the pull request template when submitting changes. Report defects through the bug report issue template.
